# Feature 02 - Schema Diff & Migration Generator

## 📌 Overview
Maintaining legacy Access 97 systems requires comparing database versions (e.g. Production DB vs Development DB) and generating DDL/DML migration scripts to update production databases or migrate to modern engines (SQLite, PostgreSQL, SQL Server).

---

## 📐 Technical Specification

### 1. Schema Comparison Engine
Compares two `AccessDatabase` models:
- **Table Differences**: Added tables, removed tables.
- **Column Differences**: Added columns, removed columns, modified data types, length changes.
- **Record Differences**: Row count discrepancies and key value mismatches.

### 2. Migration Script Generator
Generates ANSI SQL / SQLite / PostgreSQL / SQL Server migration DDL:
```sql
-- Migration Script: Generated by AccessUtility
-- Source: DevDB.mdb -> Target: ProdDB.mdb

ALTER TABLE [Customers] ADD COLUMN [TaxID] VARCHAR(50);
CREATE TABLE [NewInvoices] (
    [InvoiceID] INT PRIMARY KEY,
    [TotalAmount] DECIMAL(19,4)
);
```

---

## 🎯 User Interface Integration

### CLI Command
```bash
AccessUtility.exe diff DevDB.mdb ProdDB.mdb --output migration.sql
```
